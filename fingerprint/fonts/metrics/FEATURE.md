# fingerprint/fonts/metrics

Category: spoof
Prefs: zoom.stealth.text.system_quality, zoom.stealth.text.coverage_ladder, gfx.font_rendering.cleartype_params.rendering_mode (read through an atomic mirror, StealthTextMeasuring.h)
Test: gtest StealthFontMetrics.* (gfx/tests/gtest/TestStealthFontMetrics.cpp, Linux: the average character width is DirectWrite's, also off the main thread; advance and ink box from the design of the face; release of the design font), StealthGlyphCoverage.A8MaskIsOnTheLadder (same file), StealthTextQuality.* (gfx/tests/gtest/TestStealthTextQuality.cpp, Windows: declared text quality, no call to the host's DirectWrite); wrapper e2e test_canvas_text_is_what_retail_windows_draws, test_coloured_text_is_what_retail_windows_draws, test_text_under_a_cleartype_key_is_what_retail_windows_draws, test_system_fonts_and_colours_match_windows_retail

## What it does

Declares the metrics and the drawing of text the way Windows has them, so that no value a page reads comes from the host:
- the Windows text quality (zoom.stealth.text.system_quality: 0, 4 or 5, anything else refuses) and the ClearType parameters are declared, DirectWrite's own defaults are never asked (gfxDWriteFonts.cpp);
- on the FreeType backend the glyph advance, the ink box and the average character width are the design values of the face read through HarfBuzz (never FreeType's hinted ones) scaled by the unrounded size, as gfxDWriteFont does;
- the vertical metrics of a bundled face are the manifest's (the call lives in fonts/bundle, StealthBundleFontList.cpp);
- the coverage of an A8 glyph mask is snapped to the declared ladder before any mask filter.

## Hooks in Mozilla files

All hooks are one line with the marker `// STEALTH-HOOK(fingerprint/fonts/metrics)` and no other comment; the explanations below used to be comments in the Mozilla files.

- `gfx/skia/skia/src/core/SkScalerContext.cpp`: `#include "mozilla/gfx/StealthGlyphCoverage.h"` in a block after Skia's includes (registration), and `mozilla::gfx::StealthQuantiseGlyphCoverage(*unfilteredGlyph);` in SkScalerContext::getImage (anchor: right after the `if (!fGenerateImageFromPath) {...} else {...}` block that fills the mask, before `if (fMaskFilter)`). The call sits before the mask filter on purpose: a blur must act on the already quantised mask, and after getImage the output mask is already blurred, so neither a guard at the top nor a wrap of the function fits; the mask is born in three places (DirectWrite, FreeType, from a path), so a wrap of an expression does not fit either. The function takes the glyph and does the kA8 check itself (a colour glyph is kARGB32 and never reaches it); it reads the image through SkGlyph::mask(). The header declares `class SkGlyph;` and nothing else of Skia. This replaces the readback-time coverage ladder that was removed from CanvasRenderingContext2D. This file is in the vendored Skia tree, so every Skia update can conflict with the block.
- `gfx/thebes/gfxDWriteFonts.cpp` (Windows):
  - `#include "StealthTextQuality.h"` in a block of ours after Mozilla's includes (registration);
  - `if (StealthTextQualityDeclared()) return StealthDeclaredTextQuality();` at the top of GetSystemTextQuality (guard with a value, G15): with the engine on the declared quality is returned (only 0, 4 or 5; anything else calls StealthRefuse) and SystemParametersInfo is never asked;
  - the receiver of `CreateRenderingParams` in gfxDWriteFont::UpdateClearTypeVars is `StealthDWriteFactory(Factory::GetDWriteFactory())` (wrap-expression, the second line of Mozilla's call is unchanged): with the engine on the proxy answers E_FAIL without calling DWrite, so the caller goes down its own failed-factory road with the declared values; with the engine off it forwards to the real factory. The receiver is wrapped, not the result, because the host is read by the call itself;
  - the condition of the ClearType prefs block is `StealthClearTypeParamsApply(<Mozilla's condition>)`: true with the engine on whatever the declared quality, otherwise Mozilla's own condition. The six hard-coded defaults of UpdateClearTypeVars remain as the stock Firefox baseline; with the engine on every one of them is declared.
  GDI gamma (GetSystemGDIGamma) is still read from the host, on purpose: it only feeds the GDI-classic rendering settings, and canvas text never takes that road (allowForceGDIClassic is false for every font it uses), so no page can read a pixel it shapes.
- `gfx/thebes/gfxFT2FontBase.cpp` (Linux and Android; the glyph extents come from HarfBuzz design-space values, never from FreeType's hinted ones, engine rule 7):
  - `#include "StealthDesignMetrics.h"` in a block of ours (registration);
  - `StealthDWriteAveCharWidth(*this, mMetrics);` in InitExtraMetrics (anchor: after the `if (aveCharWidth == 0.0)` block; it replaces the value Mozilla then uses at once for maxAdvance; a guard at the top would be overwritten by Mozilla's later writes, and the value is born in several writes; `mMetrics` is the protected field it changes, passed as argument);
  - `StealthDesignAdvance(*this, aGID, bold.x, aAdvance);` in GetFTGlyphExtents (anchor: after Mozilla's `if (aAdvance) {...}` block, before `if (aBounds)`; it overwrites *aAdvance with the design advance times the unrounded size plus the synthetic-bold strength; Mozilla's block is pure arithmetic on the loaded glyph slot, so the final value is the same as when it was skipped; it needs `bold.x`, a local born after the glyph is loaded and from a private member function, so a guard at the top and a wrap of the function do not reach it; the COLR fallback below reads the overwritten *aAdvance, as before);
  - `if (StealthDesignGlyphBounds(*this, aGID, aBounds)) return true;` at the top of GetGlyphBounds (guard).
  Measurements behind it: Courier New is 1229 units on a 2048 em and at a requested 13.383333 px Windows reports 8.0313 px per glyph while the FreeType path reported 7.8022 (1229 * 13 / 2048, the right arithmetic on the wrong ppem); measureText's four actualBoundingBox fields matched Windows on 12960 of 12960 fields and differed on Linux on 1440 before the ink box came from the design; a CFF webfont diverged on 108 of 150 fields when the design path had a FreeType fallback, which it no longer has; Consolas at 13 px and DPR 1.5 has an average character width of 10.7212 on Windows against 11 on Linux (a default textarea 143 px against 146.667 px wide).
- `gfx/thebes/gfxFont.cpp`: `#include "StealthTextMeasuring.h"` in a block of ours (registration; the header also brings StealthBundleFontList.h for the SanitizeMetrics hook); `StealthTextMeasuringInit();` as the first statement of gfxFontCache::Init (notice: registers the any-thread mirror of the declared rendering mode, main thread); `StealthImposeBundleVMetrics(mFontEntry, GetAdjustedSize(), &mMetrics);` in gfxFont::SanitizeMetrics (anchor: right after the zero-size early return, whose memset of mMetrics is what the hook then imposes on; the lines below read mMetrics, so a guard or a wrap cannot stand before them). For a bundled face the manifest's vertical metrics overwrite maxAscent, maxDescent, emHeight, emAscent, emDescent, the leadings, xHeight, capHeight and the underline and strikeout values, then the existing clamps run. The function lives in fonts/bundle (gfx/thebes/StealthBundleFontList.cpp).
- `gfx/thebes/gfxFont.h`: `bool GetStealthHostIndepVMetrics(gfxFloat&, gfxFloat&, gfxFloat&, gfxFloat&);` next to the vertical-metrics accessor (member). Defined in fonts/bundle (StealthBundleFontList.cpp); it reads OS/2 directly so canvas TextMetrics' vertical fields are host-independent.
- `gfx/thebes/gfxHarfBuzzShaper.h`: `friend struct StealthDesignFontAccess;` after the destructor and `mutable hb_font_t* mDesignFont = nullptr;` after mHBFont (members). StealthDesignFontAccess (StealthDesignFontAccess.h, defined in StealthDesignMetrics.cpp) builds a second hb_font on the same face, used only for design-space metrics and never for shaping: scale = unitsPerEm, hb_ot_font_set_funcs pinned (HB_FONT_FUNCS from the environment must not redirect to a host rasteriser), variations applied. It holds the shaper's recursive mMutex because the shaper is shared through gfxFontCache. The face is bound through a named AutoHBFace: an earlier unnamed binding was a dangling pointer (content-process crashes, feature hb-face-lifetime).
- `gfx/thebes/gfxHarfBuzzShaper.cpp`: `#include "StealthDesignFontAccess.h"` in a block of ours (registration) and `StealthReleaseDesignFont(mDesignFont);` in the destructor, right after the shaping font's own hb_font_destroy (anchor: a release stays in the destructor body at the moment it always had, not in a RAII member, G39).
